# 개념과 작동 과정 중심의 편집 기록

| [CH09 Fresnel과 시선 각도](Chapters/CH09_Fresnel.md) | 24 | BRDF와 투과 모델 안에서 반사와 투과의 비중을 정하는 데 쓰입니다. 물·유리·코팅이 보는 각도에 따라 다르게 보이는 물리적 근거입니다. |

| [CH11 Substrate와 물질 구성](Chapters/CH11_Substrate.md) | 28 | 고정된 모델의 제한된 입력만 고르는 대신 물질 단위와 관계를 연결해 복합 표면을 표현합니다. 도장·코팅·물기·산란 같은 재료의 구성을 설명할 수 있게 합니다. |
| [CH12 Translucency와 합성](Chapters/CH12_TranslucencyRefraction.md) | 30 | 앞면 하나만으로 색이 정해지는 불투명 표면과 달리 여러 표면의 색을 합쳐 화면을 구성합니다. 유리·물·연기가 배경과 어울리도록 만드는 렌더링 영역입니다. |
| [CH13 SSS와 표면 아래 산란](Chapters/CH13_SubsurfaceScattering.md) | 32 | 피부·왁스·대리석 등에서 부드러운 음영과 내부 빛 전달에 의한 색을 표현합니다. 표면 반사만으로는 만들기 어려운 재료의 밀도감을 담당합니다. |

| [CH15 Instancing과 반복 배치](Chapters/CH15_Instancing.md) | 36 | 반복 오브젝트를 개별적으로 관리하고 제출하는 부담을 줄일 수 있습니다. 여러 복사본이 보이는 사실 자체를 없애는 것이 아니라 중복 데이터와 준비를 공유하는 역할입니다. |

| [CH26 GPU Profiler와 개선 검증](Chapters/CH26_GPUProfiling.md) | 58 | 느린 프레임을 구성하는 작업을 찾아 아트 변경의 가설과 연결합니다. 도구는 비용의 위치를 보여 주며, 어떤 제작 선택이 원인인지는 비교 실험으로 검증합니다. |

## 핵심 수정

- CH01 첫 쪽에 렌더링 파이프라인의 정의와 장면 입력·이미지 출력, 다섯 처리 단계의 전달 데이터를 명시했습니다.
- 좌표 변환·래스터화·보간에서 표면 데이터·조명·그림자·합성·후처리로 이어지는 전체 구조를 설명합니다.
- 형상·텍스처·재질·조명·후처리 변경이 각 계산과 외관에 미치는 영향을 연결했습니다.
- CH10은 셰이더 프로그램과 머티리얼의 관계, 준비와 실행, 정점·픽셀·컴퓨트 역할을 복원했습니다. WPO는 정점 계산의 확인 예제입니다.
- CH11은 Substrate 물질 구성, CH21은 Lumen의 동적 전역 조명과 반사 등 주제의 전체 범위를 정의합니다.
- 모든 챕터의 상위 제작 목적과 비용을 예제보다 먼저 설명하고, 핵심 요약은 예제의 결과 대신 주제 전체의 역할을 정리합니다.
- 기존 엔진 캡처·출처 자료·상세 제작 기록을 보존했습니다. CH02–26의 새로운 기능 구현과 실측은 별도 작업입니다.
