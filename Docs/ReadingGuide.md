# 읽는 순서

각 챕터는 중심 질문 하나에 답합니다. 답을 먼저 읽고 원인과 과정을 이해한 뒤 그림과 실험으로 확인합니다.
왜 알아야 할까는 다른 장면에도 적용할 학습 목적이고, 예제 목표는 이번 비교에서 확인할 작은 과제입니다.

1. 중심 질문과 먼저 알아둘 답을 읽습니다.
2. 본문의 원인과 결과를 따라갑니다.
3. 그림이 보여 주는 변수와 관찰 위치를 찾습니다.
4. 예상 결과를 읽은 뒤 한 변수만 바꾸는 실험을 합니다.
5. 예상과 다르면 조건과 가정을 점검하고 실제 제작의 선택으로 연결합니다.

진단 화면은 실행 시간의 대체 지표가 아닙니다. 화면의 차이와 측정한 성능을 구분합니다.
성능은 같은 기기·카메라·노출·출력·품질을 유지하고 로딩과 셰이더 준비 뒤 반복 측정합니다.
본문의 정의는 현재 원리에 필요한 만큼만 설명하며, 예외와 구현 조건은 마지막에 둡니다.

CH01은 실제 씬과 촬영 자료가 있습니다. CH02부터 CH26은 기본 레벨과 예제 제작·검증 절차입니다.
이번 편집에서 해당 특화 예제를 새로 제작하거나 성능 실측을 수행한 것은 아닙니다.
