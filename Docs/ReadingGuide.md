# 이 문서를 읽는 방법

CH01의 CPU와 GPU, 모델과 정점, 셰이더와 래스터화 설명을 먼저 읽습니다.
각 챕터에서는 실무에서 필요한 판단을 상위 목표로, 예제에서 확인할 내용을 하위 목표로 둡니다.

## 본문을 따라 읽기

현재 원인과 결과를 이해하는 데 필요한 용어는 사용하는 자리에서 뜻을 풉니다.
메뉴와 명령은 실제 에디터에서 찾도록 영문 이름을 함께 사용합니다.
예제에서는 무엇을 바꾸고 어떤 결과를 관찰하는지 연결해 읽습니다.

## 더 깊게 읽기

수식과 구현 조건은 [보충 주석](SupplementaryNotes.md)에서 확인합니다.
이미 배운 뜻을 찾을 때는 [용어집](Glossary.md)을 사용하고, 챕터 끝의 관련 개념 링크로 이동합니다.

## 같은 조건으로 검증하기

카메라·화면 크기·노출·조명·품질 설정을 기록하고 한 변수만 바꿉니다.
정지 화면과 이동 영상을 함께 보고, 실행 시간은 안정된 조건에서 같은 길이로 반복 측정합니다.
셰이더 준비와 로딩을 마치는 워밍업, 첫 진입 비용, 고해상도 캡처 중의 작업은 별도로 기록합니다.

FPS는 초당 프레임 수, ms는 1초의 천분의 1인 시간 단위입니다.
설정값과 셰이더 통계, 실제 실행 시간은 다른 지표이므로 목표 기기에서 함께 확인합니다.

CH01은 실제 제작과 캡처가 완료되었습니다. 나머지 챕터의 실습은 기본 레벨에서 제작·검증할 절차입니다.

## 이번 판에서 달라진 읽는 순서

각 챕터 첫 쪽에서 학습 목표·원리·작동 과정과 실제 그림을 읽습니다. 다음 쪽에서 제작과 검증에 적용합니다. 모든 챕터에 관찰과 판단, 오판 방지 항목이 있습니다.
