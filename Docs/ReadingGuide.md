# 렌더링 기술 포스트 모음

게임 배경 아티스트를 위해 렌더링의 개념과 제작의 관계를 풀어 쓴 26편의 블로그 원고입니다.
각 글은 도입에서 주제를 소개하고, 원리와 그림·제작 사례를 연결한 뒤 성능과 표현의 의미를 정리합니다.
목표·실습 절차·과제 대신 읽는 흐름으로 구성했으며, 각 원고는 독립된 포스트로 사용할 수 있습니다.

직접 제작한 개념도와 엔진 캡처, 외부 이미지를 캡션에서 구분합니다.
외부 사례의 버전과 수치를 현재 프로젝트의 결과로 일반화하지 않습니다.
엔진 프로젝트의 레벨과 생성 도구는 원고와 별도로 보존됩니다.
