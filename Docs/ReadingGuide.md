# 읽는 순서

주제 자체를 이해하는 것이 먼저이고 사례와 실습은 그 설명을 뒷받침합니다.
렌더링 파이프라인은 장면이 이미지가 되는 전체 구조로, 각 기술은 그 안에서 맡는 역할로 이해합니다.

1. 무엇인가에서 개념의 정의를 읽습니다.
2. 렌더링에서 맡는 역할과 입력·출력을 연결합니다.
3. 작동 과정을 따라 데이터가 어떻게 바뀌는지 이해합니다.
4. 왜 배경 제작에 필요한지, 어떤 선택과 비용에 영향을 주는지 읽습니다.
5. 예제의 작은 확인 목표와 예상 결과를 보고 실습합니다.
6. 핵심 요약으로 주제 전체의 역할을 다시 정리한 뒤 예외·심화 조건을 읽습니다.

증상이나 예제 하나가 주제 전체의 정의를 대신하지 않습니다. 정의를 용어집에만 남기지 않습니다.
예제 목표는 상위 학습 목적 아래에 두고, 그림은 전체 구조 또는 특정 적용 중 무엇을 보여 주는지 표시합니다.
진단색은 실행 시간과 같은 지표가 아닙니다. 실제 성능은 고정한 조건에서 준비 작업 뒤 반복 측정합니다.

CH01은 실제 씬과 촬영 자료가 있습니다. CH02부터 CH26은 기본 레벨과 특화 예제 제작·검증 절차입니다.
이번 문서 수정에서 새로운 엔진 예제 구현이나 성능 실측을 수행한 것은 아닙니다.
